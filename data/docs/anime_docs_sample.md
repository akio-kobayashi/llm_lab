# `anime_docs_sample.jsonl` 参照用サンプル

`anime_docs_sample.jsonl` の内容を、人が読みやすい形に整えた一覧です。

## 構成

- 1〜10件目: 既存のオリジナルデータ
- 11〜20件目: 第1弾の追加データ
- 21〜50件目: 第2弾の追加データ

既存10件は互換性のためにそのまま残し、末尾に近い意味の作品を追加しています。

## データ形式

各行は 1 件の JSON オブジェクトです。主な項目は次のとおりです。

- `doc_id`: 文書ID
- `title`: 作品名
- `section`: 文書の種類や見出し
- `text`: 本文
- `source_url`: 参照元URL
- `retrieved_at`: 取得日
